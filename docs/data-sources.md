# Источники и атрибуция · Sources and attribution

Атрибуция также доступна в самом приёмнике под пунктом «Источники». Каждый набор сохраняет условия своего поставщика. / Attribution is also available under **Credits** in the receiver. Each dataset retains its provider's terms.

| Данные / Data | Источник и обработка / Source and processing |
| --- | --- |
| Границы, береговая линия, дороги / Borders, coastline, roads | Границы в формате world-atlas и упрощённые маршруты, общественное достояние. / World-atlas boundaries and simplified road geometry, public domain. [Natural Earth](https://www.naturalearthdata.com/about/terms-of-use/) · [world-atlas](https://github.com/topojson/world-atlas) |
| Города / Places | Записи отфильтрованы, координаты округлены, данные разбиты на области. / Filtered and tiled records with rounded coordinates. [GeoNames](https://www.geonames.org/export/) · [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) |
| Рельеф / Relief | Дневная текстура с цветокоррекцией. / Color-adjusted Earth Day Map by INOVE. [Solar System Scope](https://www.solarsystemscope.com/textures/) · [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) |
| Спутниковое изображение / Satellite imagery | Blue Marble Next Generation, Reto Stöckli / NASA GSFC. Изображение перекодировано в WebP. / Image converted to WebP. [NASA Earth Observatory](https://science.nasa.gov/earth/earth-observatory/blue-marble-next-generation/base-topography-bathymetry/) |
| Ночные огни / Night lights | Black Marble 2016, Suomi NPP VIIRS, Miguel Román / NASA GSFC. Из яркости построен слой огней. / Brightness used to render city lights. [NASA Earth Observatory](https://science.nasa.gov/earth/earth-observatory/earth-at-night/maps/) |
| Контуры застройки / Built-up areas | Liu et al., Global Urban Envelopes 2025. Геометрия упрощена и разбита на области. / Simplified and tiled geometry. [GUE 2025](https://doi.org/10.5281/zenodo.19630155) · [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) |
| Реки / Rivers | Allen & Pavelsky, Global River Widths from Landsat. Геометрия упрощена и разбита на области. / Simplified and tiled geometry. [GRWL](https://doi.org/10.5281/zenodo.18624542) · [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) |
| Озёра / Lakes | Messager et al., HydroLAKES. Геометрия упрощена и разбита на области. / Simplified and tiled geometry. [HydroLAKES](https://www.hydrosheds.org/products/hydrolakes) · [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) |
| Интернет-радио / Internet radio | Каталог с локальным снимком и ссылками на эфиры. / Station directory with a local snapshot and links to broadcaster streams. [Radio Browser](https://www.radio-browser.info/) |

FM-слой строится из опубликованных параметров передатчиков и контуров зон. В карточке передатчика можно открыть источник конкретной записи. / The FM layer uses published transmitter parameters and coverage contours. Each transmitter detail links to its source.
